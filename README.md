# 寒假工具集

一个包含日程表管理和阅读题生成器的Web应用。

## 功能

1. **寒假每日任务日程表** - 管理每日学习任务，记录学习进度
2. **寒假阅读题生成器** - 从JSON文件生成阅读理解题

## 快速开始

### 1. 启动服务器

首先需要启动后端服务器来保存JSON数据：

```bash
node server.js
```

服务器将在 `http://localhost:3000` 启动。

### 2. 打开首页

在浏览器中打开 `index.html` 文件。

### 3. 使用功能

#### 日程表功能
1. 点击"寒假每日任务日程表"卡片
2. 输入姓名和班级信息
3. 管理每日任务，标记完成情况

#### 阅读题生成器功能
1. 点击"寒假阅读题生成器"卡片
2. 选择JSON数据文件
3. **系统会自动将JSON文件保存到 `@read` 目录**
4. 点击"生成页面"预览生成的HTML
5. 点击"下载HTML"下载生成的页面

## 文件结构

```
.
├── index.html          # 首页 - 工具集入口
├── plan.html           # 日程表功能
├── read.html           # 阅读题生成器
├── server.js           # 后端服务器
├── package.json        # 项目配置
├── template.js         # HTML模板
├── @read/              # 数据存储目录
└── 小巴掌童话故事/    # 示例JSON文件
```

## 文件命名规则

JSON和HTML文件按照以下格式命名：

```
标题 + 日期 + 随机值.扩展名
```

例如：`会跳舞的长袜子_20260126_abc123.json`

## 技术栈

- **前端**：HTML, CSS, JavaScript (Vue 3)
- **后端**：Node.js (HTTP服务器)

## 注意事项

1. 使用阅读题生成器前，必须先启动服务器 (`node server.js`)
2. 页面顶部会显示服务器状态指示器
3. 如果服务器离线，JSON文件将无法自动保存到 `@read` 目录
